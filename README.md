# achieverstechnology.com

Website for **Achievers Technology** — independent software studio, est. October 2013. *Believe it, Achieve it.*

Static site, no build step: `index.html` + `assets/`. Hosted on GitHub Pages with the custom domain in `CNAME`.

- Edit content (timeline, stack, domains, projects, email) in the `DATA` object at the top of `assets/main.js`.
- Run locally: `python3 -m http.server 5190` and open http://localhost:5190
- Hidden extras: press `` ` `` for the terminal, try `party` in it, or the Konami code.
